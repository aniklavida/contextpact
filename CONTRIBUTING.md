# Contributing

ContextPact is being built toward its first complete v1.0. Please open an issue before a large change so scope and acceptance criteria are clear.

## Development

1. Use Node.js 22.12 or newer.
2. Run `npm install`.
3. Create a focused branch.
4. Add tests with behavioural changes.
5. Run `npm run check` and `npm run format:check`.
6. Open a pull request using the template.

Do not add a cloud dependency, vector database, dashboard or new client claim without evidence and an approved design change.
